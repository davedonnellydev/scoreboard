# Scoreboard

A simple, interactive game scoreboard built with HTML, CSS, and JavaScript. This project was created as part of the [Scrimba Frontend Developer Career Path](https://scrimba.com/learn/frontend).

## ✨ Features

- Real-time score tracking for two teams.
- Responsive and clean user interface.
- Built with vanilla JavaScript—no external libraries required.

## 🚀 Live Demo

Check out the live version here: [dave-donnelly-scoreboard.netlify.app](https://dave-donnelly-scoreboard.netlify.app/)

## 📁 Project Structure



```plaintext
├── index.html   // Main HTML file
├── index.css    // Styling
├── index.js     // Scoreboard logic
├── assets/      // Fonts and other assets
└── README.md    // Project documentation
```



## 🛠️ Getting Started

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/davedonnellydev/scoreboard.git
   ```


2. Navigate to the project directory:
   ```bash
   cd scoreboard
   ```


3. Open `index.html` in your web browser.
